## 🚗 Featured Project

### Car Lease Agreement Analyzer — AI Agent

**Individual Project | Infosys Springboard AI Program**

An AI-powered application designed to make complex **car lease and loan agreements easier to understand**.

The system analyzes uploaded documents, extracts important information, identifies potentially unfavorable terms, evaluates the deal, and provides AI-powered explanations and insights.

### ✨ Key Capabilities

- 📄 Multi-format document analysis
- 🔍 OCR-based text extraction from scanned documents
- 🤖 AI-powered contract understanding using Google Gemini
- ⚠️ Detection of potentially unfavorable terms and risks
- 📊 Deal fairness scoring
- 💬 AI-powered contract chatbot
- 🔧 AI-assisted negotiation insights
- 🚗 VIN and vehicle information lookup
- 📈 Side-by-side agreement comparison

### 🛠️ Technologies Used

**Backend:**  
`Python` · `FastAPI` · `Google Gemini` · `PyMuPDF` · `Tesseract`

**Frontend:**  
`React` · `TypeScript` · `Tailwind CSS`

**Database & APIs:**  
`PostgreSQL` · `SQLAlchemy` · `NHTSA API`
